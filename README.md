# Portfolio Website

Welcome to my portfolio website! This project serves as a digital representation of my skills, experiences, projects and educational background. It showcases my journey in the tech industry, highlighting my work experience, key projects, major projects I've developed and social connections.

## Features

- **Social Connections**: Links to my professional profiles on platforms like LinkedIn, Twitter, and Instagram.
- **Work Experience**: Detailed descriptions of my roles, responsibilities, and achievements at various organizations.
- **Education**: Information about my academic background, including institutions attended, courses studied, and academic performance.
- **Projects**: Details of all my major/presentable projects I've build over the span of time. Projects with live demo, source code and description.

## Technologies Used

- **Frontend**: React.js, Tailwind CSS
- **Icons**: React Icons for visual elements
- **State Management**: Redux with persistent storage

Feel free to explore my portfolio and connect with me through the provided social links!
